# Worksheet Filler

Critical Points Machine — turn an ATI report into three critical-points worksheets.

## Use it

Open the live app:

**https://george1912.github.io/critical-points-machine/**

1. Choose your ATI report PDF  
2. Autofill the worksheet headers  
3. Write your critical points  
4. Download P1–P3 or one combined PDF  

Everything runs in your browser. Your report file stays on your device.

## Develop locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

For the Mac app:

```bash
npm run dist:mac
```
